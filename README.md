# 夸克自动搜题

读取截图目录里最新的一张图，上传到夸克搜题页面，把识别结果打印到控制台与日志。

## 这是什么

一个**零 API Key**的本地搜题工具：**用 Selenium 驱动电脑版夸克浏览器**，把「题目截图」喂给夸克自带的免费 AI 搜题能力，再把答案读回来。
不自己 OCR、不调第三方大模型，等于**白嫖夸克 AI**；只查答案、**不自动作答**。

## 主要流程

工具由**两块独立程序**配合，需同时运行（步骤 1、2 两个窗口一起开才顺畅）：

```
[雷电模拟器] 题目画面
      │ ① 定时截屏（PowerShell 截窗口）
      ▼
images/雷电模拟器.png      （最新截图，被持续覆盖）
      │ ② 搜题（Selenium 读图 → 上传夸克搜题页 → 读回答案）
      ▼
夸克 AI 答案  ──►  控制台 + logs/ 日志
```

| 步骤 | 负责程序 | 启动方式（双击 .bat） | 说明 |
| --- | --- | --- | --- |
| 0. 登录夸克 | `src\登录.py` | `bat\1-登录夸克.bat` | 首次需登录，保存 Chrome 登录态（登完关掉窗口） |
| 1. 定时截屏 | `powershell\定时截屏.ps1` | `bat\A-开始定时截屏.bat` | 每 5 秒截「雷电模拟器」窗口到 `images\雷电模拟器.png` |
| 2. 搜题读答案 | `src\手动搜题.py` / `src\自动搜题.py` | `bat\手动搜题.bat`（或 `bat\2-开始自动搜题-慎用.bat` 自动循环） | 读最新截图 → 上传夸克 → 读回答案 |

> 两块程序**不是融合成一个**，而是**要同时开两个窗口（两个 .bat）一起跑**才顺畅：
> 截屏侧持续产出最新图，搜题侧再去读这张图。

## 同类方案原理与对比

> 以下为 GitHub 上公开可见的同类「自动搜题 / 自动答题」项目，作为原理对照（检索于 2026-09）。
> 检索时**未发现「专门自动化夸克搜题」的公开仓库**，本工具的路线基本是空白赛道。

### 它们的通用原理

这类项目几乎都是同一条链路：

```
截图（截屏 / ADB 截手机屏）
   → OCR 识别题目文字（或用视觉模型直接读图）
   → 调第三方大模型 API 生成答案（GPT-4V / DeepSeek / 百炼 等）
   → 在屏幕 / 网页显示答案（有的还能自动打字或自动点击作答）
```

### 代表项目一览

| 项目 | 原理链路 | 识别方式 | 答案来源 | 是否需要 Key |
| --- | --- | --- | --- | --- |
| [AI_test_helper](https://github.com/newMeta98/AI_test_helper) | 热键 Alt+V 截图 → 视觉模型 → 显示并自动打字 | GPT-4V / DeepSeek 视觉 | OpenAI / DeepSeek | 需要 |
| [DeepSolver](https://github.com/GippokratOA/DeepSolver) | 热键截图 → OCR 文字 → 提问 | Tesseract | DeepSeek (OpenRouter) | 需要 |
| [py-exam](https://github.com/ruei0325/py-exam) | 截图 → OCR → 分析 | 阿里云 OCR | 百炼大模型 | 需要 |
| [AutoQuizX](https://github.com/Ecahy/AutoQuizX) | ADB 截图 → OCR → 题库匹配 + 推理 → 自动点击 | EasyOCR | 题库 + LLM | 需要 |
| [OCR-CopyText-And-Search](https://github.com/PuZhiweizuishuai/OCR-CopyText-And-Search) | 截图 → OCR → 搜索答案 | PaddleOCR | 搜索引擎 / 题库 | 需要 |

### 本工具的原理（差异点）

```
PowerShell 截「雷电模拟器」窗口
   → 上传截图到 夸克浏览器 AI 搜题页（Selenium 驱动 Chrome）
   → 读取夸克返回的 AI 答案
   → 打印到控制台 + 日志
```

本工具**不自己 OCR、也不调任何第三方大模型 API**，而是直接复用夸克电脑端自带的免费 AI 搜题能力。

### 优缺点对比

| 维度 | 通用 LLM 方案（上表 5 个） | 本工具（夸克自动搜题） |
| --- | --- | --- |
| 成本 | 要买 API（GPT-4V / DeepSeek / 百炼，按量付费） | **零 API Key、零费用**（夸克搜题免费） |
| 使用上限 | 受 API 额度 / 速率限制 | 夸克官方说明无次数限制（但仍要控频防风控） |
| 图 / 公式题 | 取决于所用视觉模型 | 夸克自带多模态，公式 / 图题识别较好 |
| 依赖 | 一个 API Key 即可，可跨平台 | 必须 Windows + Chrome + 夸克登录态 |
| 抗改版 | 只依赖 API，较稳 | 依赖夸克网页前端，改版要改 XPath |
| 自动作答 | 多数能自动打字 / 点击（AutoQuizX 能自动点） | 只读取答案，**不自动作答** |
| 上手门槛 | 要注册申请 Key、配 `.env` | 装好 Chrome + selenium 即可，无需 Key |

### 怎么选

- 想要**零成本、不折腾 Key、只查答案不自动答**：本工具更合适。
- 想要**跨平台 / 自动把答案填进答题框 / 离线自托管**：上表那些 LLM 方案更合适（但要承担 API 费用）。
- 二者不冲突：本工具是「白嫖夸克 AI」的轻量路径，LLM 方案是「完全自控、可自动作答」的进阶路径。

## 设计原则与后续路线

本工具的设计边界，提前说清，避免后续踩坑：

- **多引擎接入（规划中，统一走 Chrome）**：后续可能接入**多个答题引擎**，但统一都走「Selenium 驱动 Chrome」这一条路，不做脱离浏览器的方案。多引擎的意义在于**轮换使用，避免长期只盯同一个引擎被风控**（验证码 / 限频 / 蜜獾）。架构上 `src\页面操作.py` 的页面交互与 `src\配置.py` 的引擎参数已做解耦，方便后续增删引擎、按题轮换。
- **不做手机自动操控（明确排除）**：**不打算做自动操控手机答题**（例如 ADB 模拟下拉屏幕、自动点选、自动提交等）。这类行为既强依赖具体 App 前端、极易随版本失效，也**容易触碰平台违规判定（如下拉屏幕类操作被判定违规）**。本工具只在本机 Windows + Chrome 上完成「截屏 → 上传 → 读答案」，绝不改变任何远程设备 / 手机的状态。
- **只查不答（延续当前定位）**：工具只读取并显示答案，**不自动往任何答题框填字或点击提交**。自动作答类需求留给上面那些 LLM 方案，或交由用户自行处理。

## 功能特性

- **纯手动搜题（推荐）**：`bat\手动搜题.bat` 进交互循环，回车就搜当前这一题，节奏自己掌控。
- **自动搜题（⚠ 慎用）**：`bat\2-开始自动搜题-慎用.bat` 每 8-12 秒自动上传最新截图；慢速版 15-30 秒防风控（自动循环持续调接口，易被检测，建议优先手动）。
- **定时截屏**：`powershell\定时截屏.ps1`（PowerShell，系统自带无需安装）截指定窗口到 `images/`。
- **中文模块名**：所有核心 `.py` 用中文命名、互相 import，双击 `bat\` 下的 `.bat` 即可运行。
- **登录态复用**：独立 Chrome profile 保存夸克登录态，一次登录长期可用。

> 麦克风 / 语音触发功能**未包含**在本仓库，只保留手动（回车）与自动（定时）两种搜题方式。

## 环境要求

- **Windows**（截屏用 PowerShell + Win32 API，仅支持 Windows 运行）
- **Python 3.9+**，并安装依赖：

  ```powershell
  pip install -r requirements.txt
  ```

## 核心玩法：两个窗口同时开

```
┌─────────────────────────────┐        ┌─────────────────────────────┐
│  bat\A-开始定时截屏.bat      │        │  bat\手动搜题.bat            │
│  （截屏侧，常开）            │        │  （搜题侧，常开）            │
│                              │        │                              │
│  每 5 秒截一次雷电模拟器窗口 │ 写盘   │  回车 → 读最新截图 → 传夸克  │
│  → images\雷电模拟器.png     │ ─────▶ │  → 在 Chrome 里显示答案      │
└─────────────────────────────┘        └─────────────────────────────┘
```

- **截屏侧**：`bat\A-开始定时截屏.bat`，把「雷电模拟器」窗口持续截成 `images\雷电模拟器.png`。
- **搜题侧**：`bat\手动搜题.bat`（推荐，自己掌控节奏）或 `bat\2-开始自动搜题-慎用.bat`（自动循环，⚠ 慎用）。
- 两个窗口**都要开着**。换题时：先在模拟器里切到新题 → 截屏侧会自动截下新画面 → 搜题侧读最新那张。

## 快速开始（手动模式，推荐）

按下面顺序来：

| 步骤 | 双击 | 作用 |
| --- | --- | --- |
| 0 | `bat\0-环境检查.bat` | 确认 Chrome、驱动、截图目录都没问题 |
| 1 | `bat\1-登录夸克.bat` | 打开专用 Chrome，手动登录一次，登录态会被保存 |
| 2 | `bat\A-开始定时截屏.bat` | **截屏侧**：开始持续截「雷电模拟器」窗口（保持这个窗口开着） |
| 3 | `bat\手动搜题.bat` | **搜题侧**：进入交互循环，回车就搜当前这一题（保持这个窗口开着） |

> 第 1 步登录完成后，**务必关掉那个 Chrome 窗口**再执行第 2/3 步，
> 否则会提示 `user data directory is already in use`。

**日常使用**：第 2、3 步的两个窗口常开。在模拟器里切到新题 → 回到 `bat\手动搜题.bat` 的窗口按回车 → 看 Chrome 里的识别结果。

如果想**全自动**不用回车：第 3 步改用 `bat\2-开始自动搜题-慎用.bat`（每 8-12 秒自动搜一次最新截图，⚠ 易被检测，慎用）。

## 手动搜题（CLI 交互，回车才搜）

双击 `bat\手动搜题.bat`，程序常驻命令行，进入交互循环，等你按键：

| 你在 CLI 里的操作 | 效果 |
| --- | --- |
| 直接按回车 | 上传截图目录里**当前最新的一张图**（即「下一题」） |
| 输入任意文字 + 回车 | 同样触发搜索下一题 |
| 输入 `q` / `quit` / `exit` | 退出（浏览器默认保留，方便看结果） |

命令行（也可在 `src\` 下直接运行）：

```powershell
cd bat\..                       # 项目根
python src\手动搜题.py                # 进入交互模式（默认）
python src\手动搜题.py --once         # 只搜一题就退出（不进循环）
python src\手动搜题.py --close        # 退出时关掉浏览器窗口（默认保留）
python src\手动搜题.py --no-log-file  # 不写日志文件
```

要点：

- 浏览器窗口在交互期间**一直开着**，每搜一题直接在里面显示结果。
- 换题前请让截屏侧（`bat\A-开始定时截屏.bat`）先截下新画面。
- 重复运行前要先关掉上一个还开着的 Chrome 窗口（profile 不能两个进程共用）。

## 自动搜题（定时循环，⚠ 慎用）

> ⚠ 自动循环会持续调用夸克接口，容易被风控检测（俗称"中蜜獾"），**建议优先用手动搜题**（回车才搜一题）。自动模式仅在短时间验证时考虑。

| 文件 | 间隔 | 适用 |
| --- | --- | --- |
| `bat\2-开始自动搜题-慎用.bat` | 8-12 秒 | 默认，小批量 |
| `bat\3-开始自动搜题-慢速-慎用.bat` | 15-30 秒 | 遇到验证码 / 风控时 |

自动模式运行时，命令行窗口在前台时可用的快捷键：

| 按键 | 作用 |
| --- | --- |
| `F8` | 立即上传一次，忽略去重 |
| `P` | 暂停 / 继续自动上传 |
| `R` | 重新加载夸克页面 |
| `+` / `-` | 调大 / 调小上传间隔（每次 2 秒） |
| `Q` | 退出程序 |

## 定时截屏（截屏侧说明）

`powershell\定时截屏.ps1` 用 PowerShell 截取**指定 Windows 窗口**的画面（本质是屏幕可见区域裁剪，
不是后台截图；窗口必须可见、不要最小化或被遮挡），保存到本项目的 `images/` 目录（脚本在 `powershell/`
内，自动取上级目录为项目根）。

### 截屏原理：CopyFromScreen vs PrintWindow

本项目 `powershell\定时截屏.ps1` 当前用的是 **CopyFromScreen**（屏幕可见区域裁剪）：
`Capture-Window` 里先 `ShowWindow` 恢复窗口 + `SetForegroundWindow` 前置，再
`Graphics.CopyFromScreen` 把屏幕上的那块像素拷下来。因此窗口必须可见、不被遮挡，否则截到的是
别的窗口或空白。

另一种做法是 **PrintWindow**（让窗口自己把画面「画」到离屏 DC）。两者取舍：

| 维度 | CopyFromScreen（本项目现用） | PrintWindow（备选方案） |
| --- | --- | --- |
| 截最小化 / 被遮挡窗口 | ❌ 只截屏幕可见区域，最小化或盖住会黑屏 / 截到别窗 | ✅ 最小化、被遮挡也能抓到窗口本身画面，不黑屏 |
| 是否抢焦点 | ❌ 需 `SetForegroundWindow` 前置，会切窗口、打扰操作 | ✅ 静默，不抢焦点、不弹窗 |
| 是否需恢复窗口 | 需要 `ShowWindow` 恢复 + 前置 | 不需要，删掉这两行也不影响 |
| 兼容性 | ✅ 最好，浏览器 / 游戏 / 几乎所有窗口都能截（只要可见） | ❌ 硬件加速窗口（Chromium / Electron / DX 游戏）易黑屏；部分软件拦截返回空白 |
| 实现复杂度 | 简单（`System.Drawing` 自带） | 稍复杂（需改 C# API 定义 + 内部绘图逻辑） |
| 彻底隐藏（`WS_HIDE`） | ❌ 拿不到 | ❌ 同样拿不到（只能最小化 / 被遮挡） |

> 结论：本项目目前用 CopyFromScreen，雷电模拟器是普通 Win32 窗口、配合定时截屏场景简单稳；
> 若要截 Chrome / Edge 这类硬件加速窗口，再评估切 PrintWindow（需接受黑屏风险）或换 DWM
> 缩略图方案。当前 `bat\A-开始定时截屏.bat` 保留 `-TopMost` 应对被遮挡。

`bat\A-开始定时截屏.bat` 默认参数：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "powershell\定时截屏.ps1" `
  -WindowTitle "雷电模拟器" -OutputName "雷电模拟器" -IntervalSeconds 5
```

常用参数：

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-WindowTitle` | 要截的窗口标题（模糊匹配，含窗口名或进程名即可） | 空（启动后手选） |
| `-OutputName` | 输出文件名前缀，生成 `前缀.png` | 窗口标题 |
| `-IntervalSeconds` | 截屏间隔（秒） | 1 |
| `-TopMost` | 截屏时把目标窗口置顶，防被遮挡 | 关 |
| `-KeepHistory` | 保留历史截图（`前缀_时间戳.png`）而非覆盖同一文件 | 关 |
| `-XStartPct`/`-XEndPct`/`-YStartPct`/`-YEndPct` | 按窗口百分比裁剪区域（如只截题目区） | 0/100/0/100（整窗） |

注意：**`-OutputName` 必须与 `src\配置.py` 的 `image_basename` 保持一致**（默认都是 `雷电模拟器`），
否则搜题侧匹配不到图。要换截其它窗口，两处一起改。

想调整截屏间隔、改成置顶、或只截题目区域，直接编辑 `bat\A-开始定时截屏.bat` 里的 powershell 参数即可。

## 修改配置

两种方式，二选一。

**方式一**：直接改 `src\配置.py` 里的 `DEFAULTS`。其中 `image_dir` 已设为本项目内的 `images`
目录（`BASE_DIR / "images"`），与 `powershell\定时截屏.ps1` 的输出位置一致，无需再改。

**方式二**（推荐，升级不冲突）：在项目根目录新建 `config.json`，只写要改的字段：

```json
{
    "image_basename": "雷电模拟器",
    "min_delay_seconds": 15,
    "max_delay_seconds": 30,
    "result_wait_seconds": 8
}
```

常用配置项：

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| `image_dir` | 截图来源目录（本项目 `images`） | 本项目 `images` |
| `image_basename` | 截图文件名前缀，匹配 `前缀*.png` | `雷电模拟器` |
| `min_delay_seconds` / `max_delay_seconds` | 上传间隔随机区间 | 8 / 12 |
| `skip_unchanged_image` | 截图没变化时跳过上传 | `true` |
| `result_wait_seconds` | 抓取识别结果的等待时间，0 为不抓 | 6 |
| `backoff_factor` | 连续失败时间隔放大倍数 | 1.6 |
| `chromedriver_path` | 手动指定驱动，留空为自动匹配 | 空 |
| `write_log_file` | 是否写 `logs/` 日志 | `true` |

## 出问题怎么办

**第一步永远是跑 `bat\0-环境检查.bat`。**

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `user data directory is already in use` | 上一个用同 profile 的 Chrome 没关 | 关掉那个夸克 Chrome 窗口再重试 |
| `session not created` / 版本不匹配 | 驱动和 Chrome 对不上 | `chromedriver_path` 留空走自动匹配 |
| 找不到上传按钮 | 未登录 / 页面没加载完 / 夸克改版 | 先跑 `src\登录.py`；改 `src\页面操作.py` 的 `UPLOAD_TEXT_XPATH` |
| 没找到截图 | 截屏侧没开 / 窗口名不对 | 确认 `bat\A-开始定时截屏.bat` 在跑；`-WindowTitle` 能匹配到窗口 |
| 上传的图是残缺的 | 截屏正在写盘 | 程序已等文件大小稳定；仍失败就把截屏间隔和上传间隔错开 |
| 出验证码 / 429 | 频率太高触发风控 | 用慢速模式，或运行时按 `-` 调大间隔 |

## 频率与风控建议

技术上能做到很快，但越快越容易触发风控。

| 频率 | 风险 | 建议 |
| --- | --- | --- |
| 15-30 秒 | 很低 | 长时间挂机首选 |
| 10-20 秒 | 低 | 稳定使用 |
| 8-12 秒 | 中 | 默认值（自动模式） |
| 5-10 秒 | 中 | 小批量测试 |
| 3-4 秒 | 偏高 | 只建议短时间验证 |
| 1 秒 | 高 | 不建议 |

出现失败时，优先把间隔调大，而不是重试更快。
